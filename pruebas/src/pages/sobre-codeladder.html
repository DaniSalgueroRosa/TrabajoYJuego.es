Sobre codeLadder

Una web en español para programadores.

codeLadder junta dos cosas: contenidos para consultar cuando los necesitas y una ruta para aprender, peldaño a peldaño. Lo principal son los contenidos; la ruta es un complemento para quien quiere practicar.

Qué vas a encontrar

  • Temario de cada lenguaje, con el resumen arriba y el detalle abajo.
  • Cómo hacer X: recetas cortas con el código listo para probar.
  • Errores explicados: qué significa el mensaje y cómo se arregla.
  • Glosario, novedades por versión y comparativas.
  • Ruta de aprendizaje en cuatro niveles (Fácil, Medio, Difícil y Todo), con minijuegos y proyectos.

Por dónde empezamos

Empezamos por Java (Java 25 LTS), con ejemplos de consola. Después llegarán otros lenguajes, como Python, JavaScript y C. Los contenidos están en preparación y la web se irá completando.
