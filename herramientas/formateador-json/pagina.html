Pon en orden tu JSON

Un JSON que llega en una sola línea, o con la sangría desordenada, es casi imposible de leer. Pégalo aquí y obtendrás una versión limpia, con cada clave en su línea y la sangría que prefieras: dos espacios, cuatro o tabuladores. También puedes hacer lo contrario y minificarlo, quitando todos los espacios para que ocupe lo mínimo al enviarlo o guardarlo. Es útil para programadores, analistas que reciben datos de una API y cualquiera que tenga que revisar un archivo de configuración.

Lo que hace diferente a esta herramienta

  • No cambia tus datos: muchos formateadores leen el JSON y lo vuelven a escribir, y en el camino un entero largo como 12345678901234567890 se convierte en 12345678901234567000 y un 1.50 pasa a 1.5. Aquí los números y los textos se copian tal como están escritos, y solo cambian los espacios.
  • Errores comprensibles: si el JSON no es válido, ves la línea y la columna exactas y una explicación en español, como que sobra una coma final o que las claves llevan comillas simples.
  • Orden de las claves: puedes ordenarlas alfabéticamente, a todos los niveles, para comparar dos documentos con facilidad. Por defecto se respeta el orden original.
  • Claves repetidas: se avisa de ellas, porque casi siempre son un error.

Cuándo usar cada modo

Embellece para leer, revisar y depurar: los editores de código y los sistemas de control de versiones trabajan mejor con una clave por línea. Minifica para reducir el tamaño de lo que se envía por red o se incrusta en una página. Ten en cuenta que el resultado es JSON estricto, el de la norma RFC 8259: no admite comentarios, comillas simples ni comas finales, que son extensiones de otros formatos como JSON5 o JSONC. Todo el proceso ocurre en tu navegador y el contenido no se envía a ningún servidor, por lo que puedes usarlo con datos privados.

Preguntas frecuentes

¿Por qué no acepta mi JSON si funciona en mi programa?

Es posible que tu programa admita extensiones, como comentarios o comas finales. Esta herramienta sigue el estándar estricto y te indica el primer punto en el que se aparta de él.

¿Cambia el orden de las claves?

No, salvo que marques la casilla de ordenarlas. El orden original se conserva.

¿Hay límite de tamaño?

No hay un límite fijo. Con documentos de varios megabytes, el navegador puede tardar unos segundos en responder.

¿Se envía mi JSON a algún servidor?

No. Se procesa en tu dispositivo y no se guarda ni se transmite.
