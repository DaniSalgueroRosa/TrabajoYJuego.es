Tests de español: ortografía y vocabulario

Pruebas para medir cuánto español dominas: los errores de ortografía más comunes, el nivel de vocabulario, la jerga española y un test internacional de español.

Sirven para practicar y comparar tus resultados, no como certificación oficial de nivel. Son gratis y no necesitas registrarte.

Idiomas: español: 4 tests

  • Test de nivel de vocabulario de español

    Idiomas: español

    Treinta palabras, de las cotidianas a las más raras, para estimar tu nivel de vocabulario en español. Se corrige al momento, con gráfica por franjas.

    Hacer el test 5 min

  • Test de jerga española

    Idiomas: español

    Veinticuatro expresiones coloquiales de España, de «mola» a «dar sopas con honda», para ver cuánta jerga controlas. Se corrige al momento.

    Hacer el test 4 min

  • Test internacional de español

    Idiomas: español

    Veinticuatro palabras que cambian de significado según el país hispanohablante, de «carro» a «chompa». Mide tu español internacional y se corrige al momento.

    Hacer el test 4 min

  • Test de errores ortográficos comunes

    Idiomas: español

    Veinticuatro frases con un hueco para comprobar si dominas los errores más típicos: a ver / haber, hecho / echo, por qué / porque y más. Con la regla.

    Hacer el test 4 min
